# CopyExtension
A windows shell extension to add missing explorer functions directly in the directory context menu or in a cmd.

## Features
- Copy or move with 100% certainty the files are bit per bit identical on disk (100% bitwise compared, no CRC)
- Copy with native speeds or better (double buffer for extra performance)
- Nuke empty files and folders
- Hardlink complex folder structures as simple as pasting a copy
- Create your own custom file operations available directly in explorer
- Fast and simple (and yet familiar) UI
- Option to prevent having multiple jobs reading/writing on the same disk/volume/share without any manual interaction

## Old W10 Installation
- Find a release zip on github
- Unzip to any permanent folder (do not move the files afterwards)
- Run "install.bat" as admin (no reboot needed, uninstall.bat for uninstallation, this will restart explorer)
